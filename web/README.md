# web

The browser reader: a Vite + React + TypeScript app that swaps between two
editions of the same manga volume, page by page.

## Building and testing

```sh
npm ci
npm run build      # tsc -b && vite build
npm run typecheck  # tsc -b, no bundling — what CI runs
npm run test       # vitest run
```

`npm run dev` proxies `/api` and `/opds` to `taiyaku serve` (default
`http://127.0.0.1:8080`, override with `TAIYAKU_SERVE`) — see `vite.config.ts`.

## The WASM dependency

`taiyaku-wasm` is a `file:` dependency on `../crates/taiyaku-wasm/pkg`, which
is generated by `./scripts/build-wasm.sh` and gitignored. It must be built
before `npm install` picks up a real package there.

This is also why CI does not need a Rust or wasm toolchain: `resolver.ts` is
the only file that imports `taiyaku-wasm` as a *value*, and no test imports
`resolver.ts` at all. `npm run typecheck` does still open `resolver.ts` — other
modules import its *types* — but its one `taiyaku-wasm` import is marked
`@ts-ignore` for exactly the case where `pkg/` doesn't exist yet, so a missing
package degrades the typecheck rather than failing it. See `docs/ci.md` for how
`npm ci` and `npm run typecheck` behave against a clone where `pkg/` does not
exist.
