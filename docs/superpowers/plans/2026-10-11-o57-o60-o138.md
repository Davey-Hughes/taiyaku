A body that does not parse is then answered as it is now for a granted work, a hidden one and a slug no work holds. Task A1 holds that order with a test and a mutation that moves the step earlier.
- **The visible set reaches validation as a document.** A new `sidecar_as_seen(found, visible)` in `routes.rs` hands back the work's own sidecar, or `filter_sidecar_editions`'s copy for a restricted caller. `put_progress` looks its edition up in it. `notes::validate` keeps its signature and its twenty-odd callers, and delegates to a new `notes::validate_against(notes, work, sidecar, stored)` that `put_notes` calls with that document.

- **The walk covers the thirteen patterns that carry `{work}`**: nine under `/api/works` and four under `/opds/v1.2/works`. It sends five methods, each with no body and with `{}`, because a `MethodRouter` cannot be asked which methods it registers; an unregistered one answers 405 for a hidden work and an unknown slug alike.

// ---------------------------------------------------------------------------
// O60: progress, notes and truth ask the grant. A work outside it is answered
// on those six routes as a slug no work holds is.
// ---------------------------------------------------------------------------

/// One request through a fixture router, answered as its status and its body.
///
/// `if_match` and `body` are what the two document writes send; a read sends
/// neither. The body is read as text whatever it holds, so a route that
/// answers bytes can be asked too.
async fn answered(
    router: &axum::Router,
    method: axum::http::Method,
    uri: &str,
    if_match: Option<&str>,
    body: Option<&str>,
) -> (StatusCode, String) {
    let mut request = Request::builder().method(method).uri(uri);
    if let Some(tag) = if_match {
        request = request.header(header::IF_MATCH, tag);
    }
    let body = match body {
        Some(text) => {
            request = request.header(header::CONTENT_TYPE, "application/json");
            Body::from(text.to_string())
        }
        None => Body::empty(),
    };
    let response = router
        .clone()
        .oneshot(request.body(body).unwrap())
        .await
        .unwrap();
    let status = response.status();
    let bytes = axum::body::to_bytes(response.into_body(), 1 << 20)
        .await
        .unwrap();
    (status, String::from_utf8_lossy(&bytes).into_owned())
}

/// One of the six requests O60 names, as [`the_six_requests`] builds it.
struct Asked {
    handler: &'static str,
    method: axum::http::Method,
    uri: String,
    if_match: Option<String>,
    body: Option<String>,
    /// What a caller who may see the work is answered.
    seen: StatusCode,
}

/// The six requests O60 names, against `slug`: each one this server carries
/// out for a caller who may see the work, in an order each can succeed in.
///
/// The two tags are the ones a work nobody has written on answers with. They
/// are computed here because an account refused the work is never sent them,
/// and a write with no tag would be refused for that and show nothing.
fn the_six_requests(slug: &str) -> Vec<Asked> {
    use axum::http::Method;

    let notes_tag = notes_etag(&crate::notes::to_json(&crate::notes::empty(slug)).unwrap());
    let truth_tag = notes_etag(&crate::truth::to_json(&taiyaku_core::TruthDoc::new()));
    let note = format!(
        r#"{{"work":"{slug}","notes":[{{"id":"01J8","edition":"raw","slot":1,"body":"kept",
               "created":"2026-08-05T10:00:00Z","updated":"2026-08-05T10:00:00Z"}}]}}"#
    );
    let truth = r#"{"taiyaku_truth":1,"editions":{"raw":{
        "members":[{"sha256":"labelled"}],
        "pages":{"0":[{"x":0.1,"y":0.2,"w":0.3,"h":0.4,"axis":"v",
                       "kind":"dialogue","ignore":false,"text":"a"}]}}}}"#;
    vec![
        Asked {
            handler: "put_progress",
            method: Method::PUT,
            uri: format!("/api/works/{slug}/progress"),
            if_match: None,
            body: Some(r#"{"edition":"raw","slot":1}"#.to_string()),
            seen: StatusCode::NO_CONTENT,
        },
        Asked {
            handler: "get_progress",
            method: Method::GET,
            uri: format!("/api/works/{slug}/progress"),
            if_match: None,
            body: None,
            seen: StatusCode::OK,
        },
        Asked {
            handler: "get_notes",
            method: Method::GET,
            uri: format!("/api/works/{slug}/notes"),
            if_match: None,
            body: None,
            seen: StatusCode::OK,
        },
        Asked {
            handler: "put_notes",
            method: Method::PUT,
            uri: format!("/api/works/{slug}/notes"),
            if_match: Some(notes_tag),
            body: Some(note),
            seen: StatusCode::OK,
        },
        Asked {
            handler: "get_truth",
            method: Method::GET,
            uri: format!("/api/works/{slug}/truth"),
            if_match: None,
            body: None,
            seen: StatusCode::OK,
        },
        Asked {
            handler: "put_truth",
            method: Method::PUT,
            uri: format!("/api/works/{slug}/truth"),
            if_match: Some(truth_tag),
            body: Some(truth.to_string()),
            seen: StatusCode::OK,
        },
    ]
}

/// **O60: a work outside the grant is a slug no work holds**, on the six
/// routes that name a work and no edition.
///
/// Each request is sent twice by one account, granted `Shelf` alone: against
/// the work under `Other`, and against a slug no work holds. The two answers
/// are compared with each other, status and body, with the slug each names
/// put aside. Neither is compared with a sentence written here.
///
/// **Then the grant is lifted and the same six are sent again**, against the
/// same work, and each is carried out. That half is what shows the requests
/// are ones this server accepts: six malformed requests would be refused
/// alike for any slug. Between the two halves the three documents are read,
/// and nothing a refused write carried is in them.
#[tokio::test]
async fn progress_notes_and_truth_answer_a_hidden_work_as_a_slug_no_work_holds() {
    use axum::http::Method;

    let tmp = crate::test_support::Fixture::new("o60-hidden-work");
    let (router, state) = crate::test_support::router_over_a_granted_two_folder_library(&tmp);
    let hidden: String = state
        .library
        .conn()
        .query_row(
            "SELECT slug FROM work WHERE title = 'Other Library Work'",
            [],
            |row| row.get(0),
        )
        .expect("the slug of the work under `Other`");
    let unknown = "no-work-is-called-this";

    for (asked, nowhere) in the_six_requests(&hidden)
        .into_iter()
        .zip(the_six_requests(unknown))
    {
        let (status, body) = answered(
            &router,
            asked.method.clone(),
            &asked.uri,
            asked.if_match.as_deref(),
            asked.body.as_deref(),
        )
        .await;
        let (no_status, no_body) = answered(
            &router,
            nowhere.method.clone(),
            &nowhere.uri,
            nowhere.if_match.as_deref(),
            nowhere.body.as_deref(),
        )
        .await;
        assert_eq!(
            (status, body.replace(&hidden, "{work}")),
            (no_status, no_body.replace(unknown, "{work}")),
            "{}: a work outside the grant, left, and a slug no work holds, right",
            asked.handler
        );
        assert_eq!(status, StatusCode::NOT_FOUND, "{}: {body}", asked.handler);
    }

    let lifted = state
        .library
        .conn()
        .execute("DELETE FROM user_library WHERE user_id = 1", [])
        .expect("lifts the grant");
    assert_eq!(lifted, 1, "the one grant, which leaves the account no limits");

    let read = |document: &str| format!("/api/works/{hidden}/{document}");
    let (status, body) = answered(&router, Method::GET, &read("progress"), None, None).await;
    assert_eq!(
        status,
        StatusCode::NO_CONTENT,
        "the refused position write reached the store: {body}"
    );
    let (status, notes) = answered(&router, Method::GET, &read("notes"), None, None).await;
    assert_eq!(status, StatusCode::OK, "{notes}");
    assert!(
        !notes.contains("01J8"),
        "the refused note reached the store: {notes}"
    );
    let (status, truth) = answered(&router, Method::GET, &read("truth"), None, None).await;
    assert_eq!(status, StatusCode::OK, "{truth}");
    assert!(
        !truth.contains("labelled"),
        "the refused truth document reached the store: {truth}"
    );

    for asked in the_six_requests(&hidden) {
        let (status, body) = answered(
            &router,
            asked.method.clone(),
            &asked.uri,
            asked.if_match.as_deref(),
            asked.body.as_deref(),
        )
        .await;
        assert_eq!(
            status, asked.seen,
            "{}, for an account with no limits: {body}",
            asked.handler
        );
    }
    let (_, truth) = answered(&router, Method::GET, &read("truth"), None, None).await;
    assert!(
        truth.contains("labelled"),
        "the truth write an account with no limits made did not land: {truth}"
    );
}

/// a slug no work holds**, walked from `guarded_routes()` and not from a list

```rust
//! A counting semaphore, for work this server bounds by how many run at once
//! rather than by how many are asked for.
//!
//! Moved out of `cover.rs` by O57, unchanged, so that more than one module
//! can hold one. What a caller bounds, and why its number is what it is, is
//! said where that caller builds its own: `cover.rs`'s `GENERATION_LIMIT` is
//! one.
//!
//! `download.rs` does not use this. Its handlers are `async fn`s with a
//! runtime to await on, so it holds a `tokio::sync::Semaphore`. This one is
//! for code already on the blocking pool, where waiting is a parked thread.

use std::sync::{Condvar, Mutex};

/// A minimal counting semaphore, built on `Mutex` and `Condvar` so this stays
/// dependency-free.
#[derive(Debug)]
pub(crate) struct Semaphore {
    available: Mutex<usize>,
    released: Condvar,
}

impl Semaphore {
    pub(crate) const fn new(permits: usize) -> Self {
        Self {
            available: Mutex::new(permits),
            released: Condvar::new(),
        }
    }

    /// Block until a permit is free, then hold it until the returned guard
    /// drops.
    pub(crate) fn acquire(&self) -> SemaphoreGuard<'_> {
        let mut available = self
            .available
            .lock()
            .unwrap_or_else(std::sync::PoisonError::into_inner);
        while *available == 0 {
            available = self
                .released
                .wait(available)
                .unwrap_or_else(std::sync::PoisonError::into_inner);
        }
        *available -= 1;
        SemaphoreGuard { semaphore: self }
    }
}

#[derive(Debug)]
pub(crate) struct SemaphoreGuard<'a> {
    semaphore: &'a Semaphore,
}

impl Drop for SemaphoreGuard<'_> {
    fn drop(&mut self) {
        let mut available = self
            .semaphore
            .available
            .lock()
            .unwrap_or_else(std::sync::PoisonError::into_inner);
        *available += 1;
        drop(available);
        self.semaphore.released.notify_one();
    }
}

#[cfg(test)]
mod tests;
```

/// How many password verifies one server runs at once (O57).
///
/// **Four, by the user's ruling of 2026-10-11, and not measured.** What it
/// bounds is memory: argon2id at `credential`'s parameters holds 19 MiB for
/// each verify, and before this every request of a burst took a
/// `spawn_blocking` thread and a buffer of its own. That does not depend on
/// how fast the host is, which is why no figure from the host that runs this
/// was waited for.
///
/// **Verifies, not hashes.** The routes that set a password hash it while
/// they hold the library's one connection, so at most one of those runs at a
/// time already, and none of them takes a permit.
pub(crate) const MAX_CONCURRENT_VERIFIES: usize = 4;

/// The permits a password verify runs under: [`MAX_CONCURRENT_VERIFIES`] of
/// them for each server.
///
/// **A field of [`AuthConfig`] rather than a `static`**, so that each
/// `ServeState` has its own. One process serves one library, so in `serve`
/// the two are the same thing. In the tests they are not: a test holds every
/// permit of its own server to see what waits for one, and with a `static` it
/// would hold every other test's too wherever tests share a process, which is
/// how `.cargo/mutants.toml` runs them. `cover::tests`' `ONE_HOLDER` is what
/// that costs a `static`.
///
/// Cloning shares the permits, so a copy of the configuration is not a
/// second limit.
#[derive(Debug, Clone)]
pub struct VerifyLimit(Arc<crate::limit::Semaphore>);

impl Default for VerifyLimit {
    fn default() -> Self {
        Self(Arc::new(crate::limit::Semaphore::new(
            MAX_CONCURRENT_VERIFIES,
        )))
    }
}

impl VerifyLimit {
    /// Wait for a permit, and hold it until the returned value drops.
    ///
    /// **It blocks, so it is called on the blocking pool and never on a
    /// runtime worker**, like the SQLite reads on either side of it.
    ///
    /// **Take it before the library's connection, and never while holding
    /// the connection.** A verifying path holds its permit and then asks for
    /// the connection. Anything that held the connection and waited here
    /// would stop every one of them, and they it.
    #[must_use = "a permit that is not kept is given back at once"]
    pub(crate) fn permit(&self) -> VerifyPermit<'_> {
        VerifyPermit {
            _held: self.0.acquire(),
        }
    }

    /// Every permit at once, so that the next verify waits until they drop.
    #[cfg(test)]
    pub(crate) fn hold_all(&self) -> Vec<VerifyPermit<'_>> {
        (0..MAX_CONCURRENT_VERIFIES)
            .map(|_| self.permit())
            .collect()
    }
}

/// One of a server's verify permits, given back when it drops.
#[derive(Debug)]
pub(crate) struct VerifyPermit<'a> {
    _held: crate::limit::SemaphoreGuard<'a>,
}

/// permit.
///
/// **The one place this crate runs argon2 over a password somebody offered.**
/// It takes the permit it does not use so that a verify cannot be written

/// The address every `oneshot` request is held against: `auth::client_of`'s
/// stated placeholder for a request that carries no peer.
const NO_PEER: &str = "0.0.0.0";

/// How long a test leaves the requests it has sent before it acts.
///
/// **Only a wrong implementation makes use of it.** A request waiting for a
/// permit this test holds is still waiting however long this is, so a correct
/// run reads the same on a machine of any speed. A request that should have
/// waited and did not needs time to get past the point it should have
/// stopped at, and this is that time.
const SETTLE: std::time::Duration = std::time::Duration::from_millis(300);

/// How long any of these tests waits for its answers before it fails.
const LIMIT: std::time::Duration = std::time::Duration::from_secs(20);

/// How many requests a burst sends.
const BURST: usize = 12;

// More than there are permits, or no implementation could exceed the bound
// the burst tests assert.
const _: () = assert!(BURST > MAX_CONCURRENT_VERIFIES);

/// Puts `key`'s failures at `count`, inside the current window.
fn wind(state: &ServeState, key: &str, count: i64) {
    let conn = state.library.conn();
    account::note_failure(&conn, key).expect("records a failure to wind from");
    conn.execute(
        "UPDATE login_attempt SET count = ?2 WHERE key = ?1",
        rusqlite::params![key, count],
    )
    .expect("winds the counter");
}

/// Sends every request at once, each on a task of its own.
fn send_all(
    state: &Arc<ServeState>,
    requests: Vec<Request<Body>>,
) -> Vec<tokio::task::JoinHandle<StatusCode>> {
    requests
        .into_iter()
        .map(|request| {
            let router = build_router(state.clone());
            tokio::spawn(async move {
                router
                    .oneshot(request)
                    .await
                    .expect("answers")
                    .status()
            })
        })
        .collect()
}

/// What each of `sent` was answered, in the order they were sent, or `None`
/// if they had not all answered within [`LIMIT`].
async fn answers(sent: Vec<tokio::task::JoinHandle<StatusCode>>) -> Option<Vec<StatusCode>> {
    tokio::time::timeout(LIMIT, async {
        let mut statuses = Vec::with_capacity(sent.len());
        for handle in sent {
            statuses.push(handle.await.expect("the request did not panic"));
        }
        statuses
    })
    .await
    .ok()
}

/// Sends `request` while this test holds every permit, raises `key` to
/// `ceiling` while the request waits, frees the permits, and answers what the
/// request was told.
///
/// `key` is under its ceiling when the request arrives, so the request passes
/// the read it makes before it waits. The read it makes once it holds a
/// permit comes after the raise, and refuses it as locked out. A request
/// that does not ask again, or never waited, is verified instead.
async fn told_after_waiting(
    state: &Arc<ServeState>,
    request: Request<Body>,
    key: &str,
    ceiling: i64,
) -> StatusCode {
    let held = state.auth.verifies.hold_all();
    let sent = send_all(state, vec![request]);
    tokio::time::sleep(SETTLE).await;
    wind(state, key, ceiling);
    drop(held);
    answers(sent)
        .await
        .expect("the request answers once the permits are free")[0]
}

/// Sends `request` while this test holds every permit, and answers what it
/// was told while they were still held, or `None` if it waited for one.
async fn told_while_every_permit_is_held(
    state: &Arc<ServeState>,
    request: Request<Body>,
) -> Option<StatusCode> {
    let held = state.auth.verifies.hold_all();
    let sent = send_all(state, vec![request]);
    let answered = answers(sent).await;
    // Before the caller asserts, so a request this has shown to be waiting is
    // let go and the runtime can shut down.
    drop(held);
    answered.map(|statuses| statuses[0])
}

/// Sends `requests` while this test holds every permit, so that all of them
/// have passed the read each makes before it waits, and are waiting, before
/// any is let through. Then frees the permits and answers what each was
/// told.
async fn burst(state: &Arc<ServeState>, requests: Vec<Request<Body>>) -> Vec<StatusCode> {
    let held = state.auth.verifies.hold_all();
    let sent = send_all(state, requests);
    tokio::time::sleep(SETTLE).await;
    drop(held);
    answers(sent)
        .await
        .expect("every request answers once the permits are free")
}

/// What a burst may come to against a counter that stood one failure under
/// its ceiling.
///
/// Every request of it passes the read it makes before it waits. Of the
/// reads made under a permit, the ones that come before the first failure
/// lands are verified and answered `refused`, and every later one is locked
/// out. A permit is held from that read until the failure is recorded, so
/// the first group all hold permits at one moment: it is at most
/// `MAX_CONCURRENT_VERIFIES`, whatever the scheduling.
fn assert_one_allowance(statuses: &[StatusCode], refused: StatusCode) {
    let verified = statuses.iter().filter(|status| **status == refused).count();
    let locked = statuses
        .iter()
        .filter(|status| **status == StatusCode::TOO_MANY_REQUESTS)
        .count();
    assert_eq!(
        verified + locked,
        statuses.len(),
        "an answer that is neither a refusal nor a lockout: {statuses:?}"
    );
    assert!(
        verified >= 1,
        "the last of the allowance was not spendable: {statuses:?}"
    );
    assert!(
        verified <= MAX_CONCURRENT_VERIFIES,
        "{verified} of {} requests were verified against a counter one failure under its \
         ceiling. Only a request holding one of the {MAX_CONCURRENT_VERIFIES} permits can \
         read that counter before the first failure lands: {statuses:?}",
        statuses.len()
    );
}

/// **The order is the permit, then the library's connection.** A login, a
/// Basic request and a password change all wait for a permit, and while they
/// wait the connection is free for anyone.
///
/// The other order is a server that stops: a request holding the one
/// connection while it waits for a permit keeps every permit holder from the
/// read and the write it holds its permit for.
#[tokio::test(flavor = "multi_thread", worker_threads = 2)]
async fn a_request_waiting_for_a_permit_does_not_hold_the_librarys_connection() {

        vec![
            wrong_login(crate::test_support::FIXTURE_NAME),
            wrong_basic(crate::test_support::FIXTURE_NAME),
            wrong_change(&cookie),

  `Filmstrip.tsx`.** The reader's classes are `reader-` and a noun

  custom properties are `--strip-…`, and the code calls this element "the

  effect is attached once per mount and reads everything through refs;
  `reading` is the one render-scoped value the wheel needs, and it changes on
  `d` and never on a page turn. Joining the windowing effect would need one

  O146 case already flicks the rail by writing `scrollLeft` and watches the
  window follow the browser's own `scroll` event, so the wheel takes a path

- **A delta that is sideways as much as vertical, or more, is the
  browser's** (`Math.abs(deltaX) >= Math.abs(deltaY)`), which is how the

- **A handled wheel is cancelled before the rail is written to, whether or

```ts
export function wheelBy(
  wheel: { deltaY: number; deltaMode: number; ctrlKey: boolean },
  step: number,
): number {
  // A gesture that cannot be interpreted leaves the view alone. Returned as
  // `1` rather than as `NaN`: `zoomAt` declines a non-finite `by` anyway, but
  // a factor of exactly one says "no zoom was asked for" here, where the
  // decision is actually made, instead of deferring it one call.
  if (!Number.isFinite(step) || step <= 0) return 1
  const notches = wheelNotches(wheel)
  if (notches === 0) return 1
  // Up the page is `deltaY < 0` in every mode, and up is zoom in.
  return step ** (wheel.deltaY < 0 ? notches : -notches)
}

/**
 * How many notches one wheel event carries: `wheelBy`'s normalisation, on its
 * own, for a caller that wants the count and not a zoom factor. The strip's
 * rail is the other one (`tiles.ts`'s `stripWheel`).
 *
 * Never negative: which way the wheel turned is `deltaY`'s sign, and the
 * caller's to read. `0` for a wheel that cannot be read, or that carries
 * nothing.
 */
export function wheelNotches(wheel: {
  deltaY: number
  deltaMode: number
  ctrlKey: boolean
}): number {
  if (!Number.isFinite(wheel.deltaY) || wheel.deltaY === 0) return 0
  const pinch = wheel.ctrlKey && wheel.deltaMode === PIXELS
  const per = pinch
    ? PER_NOTCH.pinch
    : wheel.deltaMode === LINES
      ? PER_NOTCH.lines
      : wheel.deltaMode === PAGES
        ? PER_NOTCH.pages
        : // Pixels, and anything a future `deltaMode` adds: an unknown mode
          // read as pixels zooms too slowly, where reading it as lines or
          // pages would zoom about thirty or a hundred times too fast.
          PER_NOTCH.pixels
  return Math.min(
    Math.abs(wheel.deltaY) / per,
    pinch ? MAX_PINCH_NOTCHES : MAX_NOTCHES,
  )
}
```

```ts
/**
 * How far one notch of the wheel moves the rail, in CSS pixels: the size
 * `viewport.ts` reads one detent at in pixel mode, so a pixel-mode wheel
 * moves the rail by its own `deltaY`.
 */
const STRIP_PX_PER_NOTCH = 100

/**
 * How far one wheel event moves the rail **toward later pages**, in CSS
 * pixels — negative toward earlier ones — or `undefined` for a wheel the rail
 * leaves to the browser (O138).
 *
 * The rail draws no scrollbar, so without this a mouse has no way to move it.
 * What it takes is a vertical wheel: down is later and up is earlier,
 * whichever way the rail runs — `Filmstrip` is what turns "later" into left
 * or right. What it leaves alone:
 *
 * - `ctrlKey`, the browser's zoom and a trackpad's pinch;
 * - `shiftKey`;
 * - a delta that is sideways as much as it is vertical, or more;
 * - a wheel that cannot be read, or that carries nothing.
 *
 * The count is `viewport.ts`'s `wheelNotches`, so a wheel that reports lines
 * and one that reports pixels move the rail alike, and one event is capped
 * as it is for zoom.
 *
 * Takes the fields it reads rather than a `WheelEvent`, as `wheelBy` does, so
 * a test can hand it a plain object.
 */
export function stripWheel(wheel: {
  deltaX: number
  deltaY: number
  deltaMode: number
  ctrlKey: boolean
  shiftKey: boolean
}): number | undefined {
  if (wheel.ctrlKey || wheel.shiftKey) return undefined
  if (Math.abs(wheel.deltaX) >= Math.abs(wheel.deltaY)) return undefined
  const notches = wheelNotches(wheel)
  if (notches === 0) return undefined
  return (wheel.deltaY > 0 ? notches : -notches) * STRIP_PX_PER_NOTCH
}
```
