# Accessibility pass §4 — the markup: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every library screen and the reader say what they are — one `h1`,
a landmark, a tab title, names that say what a number counts and a hint
that describes rather than names — every one-of-N row announces its choice
in the role that fits its job, and a keyboard user can skip the sidebar
(O154, O156, O163, O164, O165, and the two rows this branch files and
closes, O173 and O174).

**Architecture:** Markup and attribute changes in the components that own
each control, plus one new hook module (`title.ts`, `useDocumentTitle`) and
one new component (`ReaderHeading.tsx`). Stylesheets change only where a
selector names an attribute that moved, where a promoted heading must keep
its size, and for the skip link. jsdom tests assert the markup a name is
computed from; a new `markup.browser.test.tsx`, plus additions to existing
browser files, asserts computed names, real key presses and layout.

**Tech Stack:** TypeScript, React 19.2 (`useId`), react-router 8.3, Vitest
4.1 (three projects: `node` for `*.test.ts`, `jsdom` for `*.test.tsx`,
`browser` for `*.browser.test.tsx` with the Playwright provider and `page`,
`userEvent`, `expect.element(…).toHaveAccessibleName/Description` from
`vitest/browser`), Biome 2.5.7, pnpm.

## Decided while planning

Readings taken from `a11y-markup` at `cba4572e` before the tasks were drawn.
Each is a fact a task depends on.

1. **jsdom computes no accessible names here.** The repository mounts with
   its own `testing/mount.ts`, deliberately without testing-library, and has
   no `dom-accessibility-api`. jsdom tests therefore assert the markup a name
   is computed from (`aria-label`, the text an `aria-labelledby` points at).
   The browser project has `expect.element(locator).toHaveAccessibleName()`
   and `toHaveAccessibleDescription()`, and `page.getByRole(role, { name })`;
   a probe on 2026-10-01 confirmed both work for a link, a textbox's
   `aria-labelledby`/`aria-describedby`, a named group, a tab's
   `selected`, and a heading.
2. **A visually hidden span inside a name adds a space before itself.**
   `.visually-hidden` is `position: absolute`, which makes the span a block;
   the same probe named `Proposals<span class=vh>, </span><span>17</span>…`
   "Proposals , 17 open". So O164 uses `aria-label`. The proposals `h1`
   (`<span class=vh>Proposals, </span>17 open`) came out "Proposals, 17
   open", because the space falls after the comma.
3. **`base.css.test.ts` refuses any selector not scoped to `.library` or
   `.login`**, so `.visually-hidden` stays in `reader.css`, which
   `index.css` loads for every screen.
4. **Biome's recommended `noNoninteractiveTabindex` is on**, so the preview's
   `tabpanel` takes no `tabIndex` (spec §4.1, corrected).
5. **`base.css` sizes headings by element** — `h1` `--text-h1` (2rem), `h2`
   `--text-h2` (1.5rem) — inside `.library` and `.login`. Login's heading
   has only an inline `margin: 0` (`Login.tsx`'s `headingStyle`) and the
   account page's has only `.account > h2 { margin: 0 }`, so promoting
   either grows it unless it is pinned. `.account-heading` sets its own
   `font-size`, so the account sections' `h3` → `h2` keeps its size.
6. **`Config.test.tsx`'s "gives every tab a screen to draw" would pass
   vacuously** once `.config` holds a hidden `h1`: it asserts
   `.config > :not(.config-nav)` exists. Task 4 tightens it.
7. **`Proposals.test.tsx` reads the `h1`'s whole `textContent` in many
   places** — directly, through its `header()` helper, and for the accepted
   and dismissed states as well as the open one. The hidden prefix changes
   each to `'Proposals, …'`; Task 4 updates them, which also pins the
   prefix's words. *Corrected 2026-10-01 during Task 4: this first said
   five assertions and listed them, from a search whose output had been cut
   short; the implementer found the rest when they failed.*
8. **`Account.test.tsx`'s page test reads the section headings as `h3`**
   (`'paints every part of the page with admin.css’s classes'`). They become
   `h2` on the page; the panel test's `h2` title and `h3` sections stay.
9. **`App` returns `null` before its session loads** (`if (!session) return
   null`), and `shown` — which the reader's title needs — is computed after
   that guard, so a hook cannot read it. `ReaderHeading` is a component
   rendered inside the reader's tree that calls `useDocumentTitle` itself.
10. **`.library` is a grid at 900 px and up.** A skip link as its first child
    would take a grid cell, so it is `position: fixed` in both states.
11. **The existing drawer test in `Shell.browser.test.tsx`** ("keeps the
    closed menu out of Tab’s reach, and Tab inside the open one") counts
    every stop outside the open drawer over thirty `Tab`s, which wrap through
    the frame back to the document's first stop. A skip link that is not
    `inert` while the drawer is open is that first stop, so this test is the
    one Task 7 watches fail.
13. *Added 2026-10-01 during Task 7.* **Biome's recommended
    `useValidAnchor` refuses an `<a>` with both `href` and `onClick`**, which
    Task 7's skip link is. The link keeps its anchor, as §4.6 designs it,
    under a `biome-ignore` that gives the reason. And with `preventDefault`
    deleted, the 1440 case left `#content` in the test frame's URL and the
    390 case then passed in the same run, so each case clears the fragment
    first.
12. **The rig for Task 8** follows the audit's and §3's (`docs/notes.md`, "The
    accessibility audit", "The reader's keyboard and screen-reader access"):
    `/home/davey/temp/manga-test/library.db` has no `-wal` or `-shm` beside
    it, so a plain copy is the whole database; `taiyaku library user add
    <name> --role admin` reads the password twice from stdin; `vite preview`
    takes `server.proxy`, whose target is `TAIYAKU_SERVE`.

```ts
/**
 * What a browser tab, its history and a screen reader's page announcement
 * call a screen (O173). Until this, every screen was `index.html`'s one
 * title.
 *
 * **Every routed screen calls `useDocumentTitle`, so none restores the title
 * it replaced when it unmounts**: the screen that mounts next sets its own.
 * A screen that stopped calling it would keep the last screen's name, which
 * each screen's own test catches by setting a stale title before it mounts.
 * The reader's panels — Account among them — set none: the reader's title
 * stays while one is open.
 */
import { useEffect } from 'react'

/** The app's name, which ends every title. `index.html` carries it alone. */
export const APP_NAME = 'taiyaku'

/** `name` and then the app's name, or the app's name alone before `name` is known. */
export function documentTitle(name: string | undefined): string {
  return name === undefined || name === '' ? APP_NAME : `${name} — ${APP_NAME}`
}

/** Sets `document.title` to `documentTitle(name)`, and again whenever `name` changes. */
export function useDocumentTitle(name: string | undefined): void {
  useEffect(() => {
    document.title = documentTitle(name)
  }, [name])
}
```

```js
// Captures, per screen and width: Playwright's ARIA snapshot, Chromium's own
// accessibility tree (CDP), the document title, the h1s, the main count and
// the first Tab stop. Usage: node capture.mjs <base-url> <out-dir>
import { mkdirSync, writeFileSync } from 'node:fs'
import { createRequire } from 'node:module'

const require = createRequire('/home/davey/projects/taiyaku/web/package.json')
const { chromium } = require('playwright')

const [base, out] = process.argv.slice(2)
if (!base || !out) throw new Error('usage: capture.mjs <base-url> <out-dir>')
mkdirSync(out, { recursive: true })

const SCREENS = [
  ['home', '/'],
  ['series', '/series/91'],
  ['search', '/search?q=one'],
  ['proposals', '/proposals'],
  ['rules', '/config/rules'],
  ['roots', '/config/roots'],
  ['users', '/config/users'],
  ['backup', '/config/backup'],
  ['account', '/account'],
]
const READER = '/read/akame-ga-kill----v01--2015--cbz'

async function save(page, name) {
  writeFileSync(`${out}/${name}.aria.yml`, await page.locator('body').ariaSnapshot())
  const cdp = await page.context().newCDPSession(page)
  const { nodes } = await cdp.send('Accessibility.getFullAXTree')
  const named = nodes
    .filter((n) => !n.ignored && n.role?.value !== 'none' && n.role?.value !== 'generic')
    .map((n) => ({
      role: n.role?.value,
      name: n.name?.value ?? '',
      description: n.description?.value ?? '',
      level: n.properties?.find((p) => p.name === 'level')?.value?.value,
      selected: n.properties?.find((p) => p.name === 'selected')?.value?.value,
    }))
    .filter((n) => n.role !== 'StaticText' && n.role !== 'InlineTextBox')
  writeFileSync(`${out}/${name}.ax.json`, JSON.stringify(named, null, 2))
  const facts = await page.evaluate(() => ({
    title: document.title,
    h1: [...document.querySelectorAll('h1')].map((h) => h.textContent),
    mains: document.querySelectorAll('main').length,
  }))
  writeFileSync(`${out}/${name}.json`, JSON.stringify(facts, null, 2))
  await cdp.detach()
}

async function firstTab(page) {
  await page.evaluate(() => {
    if (document.activeElement instanceof HTMLElement) document.activeElement.blur()
  })
  await page.keyboard.press('Tab')
  return page.evaluate(() => {
    const el = document.activeElement
    return el ? `${el.tagName} ${(el.textContent ?? '').trim().slice(0, 40)}` : null
  })
}

const browser = await chromium.launch()
const firsts = {}
for (const [width, height] of [[1440, 900], [390, 844]]) {
  const context = await browser.newContext({ viewport: { width, height } })
  const page = await context.newPage()
  await page.goto(`${base}/`)
  await page.waitForSelector('form')
  await save(page, `login-${width}`)
  await page.fill('input[autocomplete="username"]', 'a11y8')
  await page.fill('input[autocomplete="current-password"]', 'a11y-markup-pw')
  await page.click('button[type="submit"]')
  await page.waitForSelector('.library')
  for (const [name, path] of SCREENS) {
    await page.goto(`${base}${path}`)
    await page.waitForLoadState('networkidle')
    await save(page, `${name}-${width}`)
    firsts[`${name}-${width}`] = await firstTab(page)
  }
  await page.goto(`${base}${READER}`)
  await page.waitForSelector('[data-reader-page]')
  await page.waitForLoadState('networkidle')
  await save(page, `reader-${width}`)
  await page.locator('[data-reader-page]').focus()
  await page.keyboard.press('Tab')
  await save(page, `reader-bars-${width}`)
  await context.close()
}
writeFileSync(`${out}/first-tab.json`, JSON.stringify(firsts, null, 2))
await browser.close()
```
