**Goal:** Hold the Users half of the prototype the user approved with tests, fix spec §6's Users items and the §5 rules the prototype breaks, so Configuration → Users ships as a table, a new-account page and an account page, and O219 closes.

**Architecture:** The prototype's Users half is on the branch as the user tried it (`9af0228a`): `Users.tsx` routes `index` → `UserTable`, `new` → `NewAccount`, `:id` → `AccountAt` → `AccountPage` (was `UserRow`), `*` → the table; `config.ts` gives the users tab `pages: true` so `Config.tsx` routes `users/*`. `users.ts` adds `seesLine` and `lastSeen`. ## Global Constraints

- No server change. The Libraries pages stay as on `main`, except comments and shared CSS this PR must touch.
- **A test is deleted only when the spec removes its behaviour**, and the task's report names each deleted test with the spec line that removes it (§2: one account per page makes the two-cards-on-one-screen pairings moot). A behaviour that still exists in a new place is ported, not deleted.
- **A ported test that fails on a behaviour assertion is a regression candidate**: do not change its expectation; report it with the test name and what it expected, and stop for the controller. The exceptions this plan rules on are named in their task.
- Every new test is watched failing first, against the defect it names, hand-applied where the code already passes.
- Comments say why only (the reason, the invariant, what breaks); no history, no measurements, no "the card used to".
- Run each vitest project whole for any pass/fail claim: `pnpm -C web exec vitest run --project <p> --reporter=default >| <log> 2>&1`, read the summary with `grep -a`. Never pipe a test command through `tail`. A browser run that fails on import/connection errors with no failed assertion is the headless Chromium crashing (check `coredumpctl list | tail -3`, rerun the project) **or** Vite's error overlay from a file that fails to import, which covers the page for the files after it: fix the import before reading any other browser failure.
- Lint with `pnpm -C web run lint` (biome needs its config; check `git diff` for silent reformatting; one warning, `noDescendingSpecificity` in `admin.css`, is on `main` too), typecheck with `pnpm -C web run typecheck`.

- Never `cd` (it is zoxide here): absolute paths, `git -C`, `pnpm -C web`. Logs and scratch go under `/tmp/claude-1000/-home-davey-projects-taiyaku/fee33241-fe57-4581-8078-044a9106b939/scratchpad/`. zsh with noclobber: start a log with `>|`; `grep` skips "binary" logs, use `grep -a`.
