> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

> **SUPERSEDED 2026-08-13, and kept as the record of what was planned rather than what happened.** Phase A is finished; its result is `docs/notes.md`, "Fourteen fan editions, and the four signals that did not survive them". **Do not execute the tasks below as written.** Three things diverged: the sweep step's luminance ranking was found to miss cards and aspect replaced it as the primary instrument (corrected in Task 6 below); Sono Bisque Doll left the scope for want of any counterpart; and the rule that actually survived — a page's *size* against its volume's median — did not exist when this was written and appears nowhere in it. The unchecked boxes below are historical, not outstanding work.

**Goal:** Take credit-page detection's measured precision and recall from a denominator of five known credit pages across two fan editions to a denominator over fourteen, and pin the result in a test that fails when the rule moves.

**Architecture:** A checked-in JSON fixture per surveyed edition holds that edition's unpaired-run structure and a person's adjudication of every candidate. `corpus/` is gitignored, so fixtures carry run shapes and page indices and never images — which is what lets the regression test run in CI. `credits` gains a mode that emits the structural half of a fixture so only the verdicts are hand-written. Twelve fan editions are then ingested from the NAS in three waves and surveyed.

**Tech Stack:** Rust (`taiyaku-cli`, `taiyaku-core`), `serde`/`serde_json`, bash survey scripts.

- Phase B (the tier rule — §4, §5, §6 of the design) is **NOT** in this plan and must not be started. This plan ends with numbers; Phase B chooses thresholds from them.

```rust
//! An adjudicated fan edition: its unpaired-run structure, and a person's
//! verdict on what each candidate turned out to be.
//!
//! **The verdicts are not this crate's output.** Every one was earned by
//! extracting the page and looking at it, which `docs/notes.md` records as the
//! only thing that has ever found an error in this feature. A fixture
//! generated by the code under test would assert nothing, so the structural
//! half may be emitted by `credits --emit-fixture` and the `credit_pages`
//! list may not.
//!
//! Checked in rather than left beside the sidecar the way `truth.rs`'s L2
//! ground truth is: `corpus/` is gitignored and CI has no corpus, so a fixture
//! that lives there cannot gate anything. These carry page indices and run
//! shapes and never images, which is what lets them run anywhere.

use serde::Deserialize;
use std::collections::BTreeSet;

use taiyaku_core::UnpairedRun;

/// One run of unpaired pages, as recorded rather than as recomputed.
#[derive(Debug, Deserialize)]
pub struct FixtureRun {
    /// Half-open, in the edition's flat page sequence.
    pub pages: [u32; 2],
    /// Index into the edition's members.
    pub member: usize,
    /// Half-open, local to that member.
    pub local: [u32; 2],
    /// Does this run end on the member's last page? The only positional test
    /// that classifies.
    pub at_member_end: bool,
    /// Half-open, in the flat slot sequence — **`null` where it was never
    /// measured.** `is_candidate` reads `pages` and `at_member_end` only, so
    /// a fixture hand-written from a table that recorded pages must not
    /// invent a slot range to fill the field.
    pub slots: Option<[u32; 2]>,
}

impl FixtureRun {
    fn to_run(&self) -> UnpairedRun {
        let slots = self.slots.unwrap_or(self.pages);
        UnpairedRun {
            slots: slots[0]..slots[1],
            pages: self.pages[0]..self.pages[1],
            member: self.member,
            local: self.local[0]..self.local[1],
            at_member_end: self.at_member_end,
        }
    }
}

/// What one surveyed edition contributes to the two figures.
#[derive(Debug)]
pub struct Tally {
    /// What signal 1 emits, in ascending page order.
    pub candidates: Vec<u32>,
    /// How many of those are true positives.
    pub hits: usize,
    /// How many credit pages are known to exist in this edition, including
    /// any signal 1 cannot reach.
    pub known: usize,
    /// Whether this edition was exhaustively swept. Recall is reported only
    /// over swept editions — see the design's §8.
    pub swept: bool,
}

#[derive(Debug, Deserialize)]
pub struct CreditFixture {
    pub work: String,
    pub edition: String,
    pub against: String,
    pub pages: u32,
    pub slots: u32,
    /// Exhaustively swept for credit pages the survey did not surface, rather
    /// than reviewed candidate-by-candidate.
    pub swept: bool,
    pub runs: Vec<FixtureRun>,
    /// Every page known to be a credits page. Adjudicated by extraction.
    pub credit_pages: Vec<u32>,
    /// Free text: what the odd rows are, and why anything was excluded.
    #[serde(default)]
    pub notes: String,
}

impl CreditFixture {
    /// # Panics
    /// If the embedded JSON stops parsing, which is a build-time defect
    /// rather than a runtime condition.
    pub fn from_json(text: &str) -> Self {
        serde_json::from_str(text).expect("a checked-in fixture always parses")
    }

    pub fn runs(&self) -> Vec<UnpairedRun> {
        self.runs.iter().map(FixtureRun::to_run).collect()
    }

    pub fn tally(&self) -> Tally {
        let candidates = crate::credits::credit_pages(&self.runs());
        let known: BTreeSet<u32> = self.credit_pages.iter().copied().collect();
        let hits = candidates.iter().filter(|p| known.contains(p)).count();
        Tally {
            candidates,
            hits,
            known: known.len(),
            swept: self.swept,
        }
    }

    // Each fixture is named here rather than found by walking the directory.
    // A walk that resolves to nothing reads exactly like a corpus with nothing
    // to report, which is the silence this repository exists to avoid.
    pub fn gotoubun_v01() -> Self {
        Self::from_json(include_str!(
            "../fixtures/credits/gotoubun-v01-en-fan.json"
        ))
    }

    /// Every fixture, for the aggregate figures.
    pub fn all() -> Vec<Self> {
        vec![Self::gotoubun_v01()]
    }
}
```

```rust
/// The structural half of a `credit_fixture::CreditFixture`, as JSON.
///
/// `credit_pages` and `swept` are deliberately empty and false: they are a
/// person's adjudication, and a fixture whose verdicts came from the code
/// under test would assert nothing. `notes` is empty for the same reason.
fn emit_fixture_json(
    work: &str,
    edition: &str,
    against: &str,
    pages: u32,
    slots: u32,
    runs: &[UnpairedRun],
) -> String {
    let rows: Vec<serde_json::Value> = runs
        .iter()
        .map(|r| {
            serde_json::json!({
                "pages": [r.pages.start, r.pages.end],
                "member": r.member,
                "local": [r.local.start, r.local.end],
                "at_member_end": r.at_member_end,
                "slots": [r.slots.start, r.slots.end],
            })
        })
        .collect();
    let doc = serde_json::json!({
        "work": work,
        "edition": edition,
        "against": against,
        "pages": pages,
        "slots": slots,
        "swept": false,
        "runs": rows,
        "credit_pages": [],
        "notes": "",
    });
    serde_json::to_string_pretty(&doc).expect("a fixture is always serialisable")
}
```

Wire `--emit-fixture PATH` into `command` at `crates/taiyaku-cli/src/credits.rs:435`, using the three-part pattern the existing valued flags already follow. A valued flag with no value must be refused before any member is read, which is what `crate::option_value` gives for free — and the flag must also be listed as consumed, or `member_args` will take its path argument for a member.

```rust
    const KNOWN: &[&str] = &[
        "--sidecar", "--against", "--cache", "--write", "--emit-fixture",
    ];
    crate::reject_unknown_flags("credits", args, KNOWN)?;

    let sidecar = crate::option_value(args, "--sidecar", "a path to a taiyaku.json")?;
    let against = crate::option_value(args, "--against", "an edition name")?;
    let cache = crate::option_value(args, "--cache", "a directory")?;
    let emit_fixture =
        crate::option_value(args, "--emit-fixture", "a path to write the fixture to")?;
    let write = args.iter().any(|a| a == "--write");

    // Four consumed flags now, not three. A path this list forgets becomes a
    // member, and a member that is really a flag argument fingerprints as a
    // missing file rather than refusing.
    let members = member_args(args, &[sidecar, against, cache, emit_fixture]);
```

Then, after `classify` has produced its runs, write the file when the flag is present:

```rust
    if let Some(path) = emit_fixture {
        let json = emit_fixture_json(work_name, edition, counterpart, pages, slots, &runs);

    }
```

```rust
/// command produces.
///
/// `work=` is last because a work title holds spaces and runs to end of line,
/// which leaves every field before it positionally fixed —
/// `duplicate-survey.sh` and `margin-survey.sh` established that discipline

    against: &str,

    slots: u32,

    candidates: usize,
    scan: Option<&str>,
    work: &str,

        Some(group) => format!(" scan=\"{group}\""),
        None => String::new(),
    };
    format!(
        "credits: edition={edition} against={against} pages={pages} slots={slots} \
         runs={runs} candidates={candidates} bound={MAX_CREDIT_RUN}{scan} work={work}"
```

- [ ] **Step 4: Implement**

By substring rather than by pulling in an XML parser: the field is a flat element in a flat document, the crate has no XML dependency today, and adding one to read one tag would be a poor trade — CI has no cargo cache, so every dependency is compiled from scratch on every run.

```rust
/// The scanlation group `ComicInfo.xml` claims, from the first member that
/// carries one.
///
/// **Survey context only.** It names a group and never a page, so there is no
/// sound way for it to promote or demote a candidate, and nothing in
/// `is_candidate` or `credit_pages` reads it. It tells a reviewer whose habit
/// they are adjudicating.
///
/// Absent file, absent element and empty value are all `None` — an edition
/// whose ComicInfo carries `<ScanInformation></ScanInformation>` claims no
/// more than one carrying no element at all.
fn scan_information(entries: &[(String, Vec<u8>)]) -> Option<String> {
    const OPEN: &str = "<ScanInformation>";
    const CLOSE: &str = "</ScanInformation>";
    for (name, bytes) in entries {
        if !name.eq_ignore_ascii_case("ComicInfo.xml") {
            continue;
        }
        let text = String::from_utf8_lossy(bytes);
        let Some(start) = text.find(OPEN) else {
            continue;
        };
        let rest = &text[start + OPEN.len()..];
        let Some(end) = rest.find(CLOSE) else {
            continue;
        };
        let value = rest[..end].trim();
        if !value.is_empty() {
            return Some(value.to_string());
        }
    }
    None
}
```

Then pass the real value at `classify`'s call site in place of the `None` from Step 1, reading `ComicInfo.xml` from the members already being opened rather than opening them a second time.

### Task 5: The ingest script

**Files:**
- Create: `scripts/ingest-fan-edition.sh`

**Interfaces:**
- Produces: `scripts/ingest-fan-edition.sh <source-dir> <name-filter> <corpus-work>`, copying matching `.cbz` into `<corpus-work>/en-fan/` and printing one provenance line per file to stdout.

- [ ] **Step 1: Write the script**

```bash
#!/usr/bin/env bash
# Copy one volume's worth of a fan edition off the NAS into a corpus work, and
# print the provenance rows that docs/notes.md's "Provenance: where the
# measured material came from" table wants.
#
#   scripts/ingest-fan-edition.sh \
#     "/mnt/daveynet/nfs/media 1/Manga (Chapters)/Kobayashi-san cno Meidoragon - Fan Translated" \
#     ' - v1 c' \
#     corpus/kobayashi-v01
#
# The filter is a fixed string matched against the file name, not a glob and
# not a regex: the names hold brackets, apostrophes and multiplication signs,
# and every one of those is a metacharacter to something.
#
# **The source is read-only.** It is the user's media library. This script
# copies out of it and never writes, moves or deletes anything under it.
set -euo pipefail
cd "$(git rev-parse --show-toplevel)"

src="${1:?usage: ingest-fan-edition.sh <source-dir> <name-filter> <corpus-work>}"
filter="${2:?usage: ingest-fan-edition.sh <source-dir> <name-filter> <corpus-work>}"
work="${3:?usage: ingest-fan-edition.sh <source-dir> <name-filter> <corpus-work>}"

[ -d "$src" ] || { echo "error: $src is not a directory" >&2; exit 2; }
[ -d "$work" ] || { echo "error: $work is not a corpus work directory" >&2; exit 2; }

dest="$work/en-fan"
# `${dest:?}` rather than `$dest`: the colon form aborts when the variable is
# set but empty, which `set -u` does not catch and quoting does not fix. The
# suffix is the whole danger - bare "$dest" is harmless when empty, "$dest"/*
# is not.
if [ -d "$dest" ]; then
  echo "error: ${dest} already exists; remove it by hand if you mean to re-ingest" >&2
  exit 3
fi
mkdir -p "${dest:?}"

copied=0
while IFS= read -r -d '' file; do
  name="$(basename "$file")"
  case "$name" in
    *"$filter"*) ;;
    *) continue ;;
  esac
  cp -- "$file" "$dest/"
  printf '%s  %s\n' "$(sha256sum < "$file" | cut -d' ' -f1)" "$name"
  copied=$((copied + 1))
done < <(find "$src" -maxdepth 1 -type f -name '*.cbz' -print0 | sort -z)

# A run that copied nothing is a wrong filter, not an edition with no volume.
# Exiting 0 with an empty directory would put that mistake into the corpus as
# a surveyable edition holding no members.
[ "$copied" -gt 0 ] || {
  echo "error: no .cbz under $src matched '$filter'; nothing ingested" >&2
  rmdir "${dest:?}"
  exit 4
}

echo "ingest-fan-edition: $copied member(s) into $dest" >&2
```

**Aspect first. It is the strong instrument and luminance is the weak one, which is the reverse of what this plan originally said.** A credits card is page-shaped only by accident: it is a card the group made, not a scan of a printed page, so its proportions come from nowhere the volume's own pages come from.
```bash
python3 - <<'PY'
import zipfile, pathlib, struct, hashlib, statistics, json
WORK = "kobayashi-v01"          # edit per edition
def dims(b):
    if b[:8]==b'\x89PNG\r\n\x1a\n': return struct.unpack('>II', b[16:24])
    i=2
    while i<len(b):
        if b[i]!=0xFF: i+=1; continue
        m=b[i+1]
        if m in (0xC0,0xC1,0xC2):
            h,w=struct.unpack('>HH',b[i+5:i+9]); return (w,h)
        if m in (0xD8,0xD9) or 0xD0<=m<=0xD7: i+=2; continue
        i+=2+struct.unpack('>H',b[i+2:i+4])[0]
    return (0,0)
doc = json.load(open(f"corpus/{WORK}/taiyaku.json"))
pages, page = [], 0
for m in doc["editions"]["en-fan"]["members"]:      # sidecar order, authoritative
    p = pathlib.Path("corpus")/WORK/m["path"]
    z = zipfile.ZipFile(p)
    for li, n in enumerate(sorted(x for x in z.namelist()
            if x.lower().endswith(('.jpg','.jpeg','.png')) and not x.endswith('/'))):
        b = z.read(n); w,h = dims(b)
        pages.append((page, p.stem.split(" - ")[-1], li, w, h, w/h if h else 0,
                      hashlib.sha256(b).hexdigest()[:8])); page += 1
med = statistics.median(p[5] for p in pages)
print(f"{len(pages)} pages, median aspect {med:.3f}")
for p in pages:
    if abs(p[5]-med)/med > 0.15:
        print(f"  page {p[0]:3d}  {p[1]:<9s} l{p[2]:<3d} {p[3]}x{p[4]}  aspect {p[5]:.3f}  {p[6]}")
PY
```
