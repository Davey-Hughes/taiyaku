# Reader M1–M2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extract archive reading into its own crate, then build `taiyaku serve` — an HTTP server that hands a browser the sidecar, individual page images, and reading progress.

**Architecture:** `taiyaku-read` holds everything that turns a member into pages, so `taiyaku-cli` and `taiyaku-serve` derive the page sequence from one implementation rather than two. `taiyaku-serve` is axum over a `PageSource` trait; `LocalLibrary` reads the filesystem, and `StumpLibrary` (M3, not this plan) will proxy Stump behind the same trait. No browser work in this plan.

**Tech Stack:** Rust edition 2024, axum 0.8, tokio 1, tower 0.5, `zip` 7, `sha2` 0.11, `serde`/`serde_json`.

**Spec:** [`docs/superpowers/specs/2026-07-30-reader-design.md`](../specs/2026-07-30-reader-design.md)

## Global Constraints

- Rust edition 2024, `rust-version` 1.85. All crate manifests inherit `version`, `edition`, `rust-version`, `license`, `repository`, `authors` from `[workspace.package]`, and lints via `[lints] workspace = true`.
- `unsafe_code = "forbid"`. `missing_debug_implementations`, `clippy::todo`, `clippy::dbg_macro` all warn, and the gate runs clippy with `-D warnings`, so a warning is a failure.
- `taiyaku-core` must keep building for `wasm32-unknown-unknown`. **Do not add dependencies to `taiyaku-core` in this plan** — nothing here requires it.
- The gate is `scripts/check-all.sh` (fmt, clippy, tests, wasm build). It must pass before every commit.
- Work on a feature branch. Land with `scripts/land.sh -m "<subject>"`, which squashes to one commit and runs the gate on the merged tree before committing.
- **No attribution in commit messages.** No `Co-Authored-By`, no `Generated with`.
- Commit subjects on this repo are descriptive sentences ("Order an edition's members once, where the command line is read"), not bare conventional-commit prefixes. Bodies explain why.
- The page sequence rules are normative — `docs/sidecar.md`, "How a member becomes pages". Members concatenate in array order; within a member, image entries sort by whole path in natural order; non-images are not pages.
- axum 0.8 path parameters are `{name}`, **not** `:name`.
- Any shell variable feeding a recursive delete is written `"${VAR:?}"`, never `"$VAR"`.

## Decisions this plan makes that the spec left open

The spec lists these under "Open questions". They block implementation, so they are resolved here.

1. **What `{work}` names.** `taiyaku serve <sidecar>...` takes sidecar paths as arguments, matching the CLI's explicit-members style. There is no library scanning — that is Stump's job and is out of scope. A work's id is its sidecar filename stem, lowercased, with every non-alphanumeric character replaced by `-`. `Go-Toubun.taiyaku.json` → `go-toubun-taiyaku`.
2. **Where progress lives.** A sibling file, `<sidecar-stem>.progress.json`. Not inside `taiyaku.json`, which stays a pure alignment document that diffs meaningfully in git.
3. **Thumbnails are deferred to M5.** The spec lists a `/thumb` route, but the filmstrip that needs it is M5 and thumbnail caching is still an open question. Building it now would be answering that question by accident. The route is not implemented in this plan.

- [ ] **Step 4: Split name-finding from byte-reading**

In `crates/taiyaku-read/src/pages.rs`, add these functions. `directory_page_paths` and `archive_page_names` factor out the ordering logic that `read_directory` and `read_archive` already perform, so there is still exactly one place that decides page order.

```rust
/// The paths of a directory's pages, in reading order, without reading them.
fn directory_page_paths(root: &Path) -> Result<Vec<PathBuf>, String> {
    let mut found: Vec<PathBuf> = Vec::new();
    let mut pending = vec![root.to_path_buf()];
    while let Some(dir) = pending.pop() {
        let entries = std::fs::read_dir(&dir).map_err(|e| format!("{}: {e}", dir.display()))?;
        for entry in entries.flatten() {
            let path = entry.path();
            let base = path
                .file_name()
                .unwrap_or_default()
                .to_string_lossy()
                .to_string();
            if base.starts_with('.') {
                continue;
            }
            if path.is_dir() {
                pending.push(path);
            } else if is_image(&base) {
                found.push(path);
            }
        }
    }
    found.sort_by(|a, b| natural_cmp(&a.to_string_lossy(), &b.to_string_lossy()));
    Ok(found)
}

/// The names of an archive's page entries, in reading order.
fn archive_page_names(path: &Path) -> Result<Vec<String>, String> {
    let file = File::open(path).map_err(|e| format!("{}: {e}", path.display()))?;
    let mut zip = zip::ZipArchive::new(file)
        .map_err(|e| format!("{}: not a readable cbz: {e}", path.display()))?;
    let mut names: Vec<String> = (0..zip.len())
        .filter_map(|i| {
            let entry = zip.by_index(i).ok()?;
            if !entry.is_file() {
                return None;
            }
            let name = entry.name().to_string();
            if name.starts_with("__MACOSX") || name.rsplit('/').next()?.starts_with('.') {
                return None;
            }
            is_image(&name).then_some(name)
        })
        .collect();
    names.sort_by(|a, b| natural_cmp(a, b));
    Ok(names)
}

/// The names of a member's pages, in reading order, without reading any bytes.
///
/// For an archive this reads only the central directory; for a directory only
/// the listing. That is what makes serving one page of a 195-page volume cost
/// one page rather than the volume.
pub fn member_page_names(path: &Path) -> Result<Vec<String>, String> {
    if path.is_dir() {
        Ok(directory_page_paths(path)?
            .iter()
            .map(|p| {
                p.strip_prefix(path)
                    .unwrap_or(p)
                    .to_string_lossy()
                    .to_string()
            })
            .collect())
    } else {
        archive_page_names(path)
    }
}

/// One page's bytes, addressed by its index within the member.
pub fn member_page(path: &Path, index: u32) -> Result<Vec<u8>, String> {
    let i = index as usize;
    if path.is_dir() {
        let paths = directory_page_paths(path)?;
        let page = paths
            .get(i)
            .ok_or_else(|| format!("{}: no page {index}", path.display()))?;
        return std::fs::read(page).map_err(|e| format!("{}: {e}", page.display()));
    }
    let names = archive_page_names(path)?;
    let name = names
        .get(i)
        .ok_or_else(|| format!("{}: no page {index}", path.display()))?;
    let file = File::open(path).map_err(|e| format!("{}: {e}", path.display()))?;
    let mut zip = zip::ZipArchive::new(file)
        .map_err(|e| format!("{}: not a readable cbz: {e}", path.display()))?;
    let mut entry = zip
        .by_name(name)
        .map_err(|e| format!("{}: {name}: {e}", path.display()))?;
    let mut bytes = Vec::with_capacity(entry.size() as usize);
    entry
        .read_to_end(&mut bytes)
        .map_err(|e| format!("{}: {name}: {e}", path.display()))?;
    Ok(bytes)
}
```

```rust
/// A URL-safe id for a work, from its sidecar's filename.
///
/// The sidecar has a title but no id, and titles are neither unique across a
/// library nor stable across an edit. The filename is both, and a person
/// looking at a URL can tell which file it came from.
pub fn work_id(sidecar_path: &Path) -> String {
    let stem = sidecar_path
        .file_name()
        .map(|n| n.to_string_lossy().to_lowercase())
        .unwrap_or_default();
    let stem = stem.strip_suffix(".json").unwrap_or(&stem);
    let slug: String = stem
        .chars()
        .map(|c| if c.is_ascii_alphanumeric() { c } else { '-' })
        .collect();
    let trimmed = slug.trim_matches('-').to_string();
    match trimmed.is_empty() {
        true => "work".to_string(),
        false => trimmed,
    }
}

/// Read every sidecar the server was pointed at.
///
/// Two works resolving to the same id is an error rather than a silent
/// shadowing: one of them would be unreachable and nothing would say which.
pub fn load_works(paths: &[PathBuf]) -> Result<Vec<Work>, String> {
    let mut works: Vec<Work> = Vec::new();
    for path in paths {
        let text = std::fs::read_to_string(path).map_err(|e| format!("{}: {e}", path.display()))?;
        let sidecar = Sidecar::from_json(&text)?;
        let id = work_id(path);
        if let Some(clash) = works.iter().find(|w| w.id == id) {
            return Err(format!(
                "{} and {} both name the work `{id}`; rename one",
                clash.path.display(),
                path.display()
            ));
        }
        works.push(Work {
            id,
            path: path.clone(),
            sidecar,
        });
    }
    Ok(works)
}
```

```rust
impl PageSource for LocalLibrary {
    fn page(&self, work: &Work, edition: &str, index: u32) -> Result<Vec<u8>, String> {
        let ed = work
            .sidecar
            .editions
            .get(edition)
            .ok_or_else(|| format!("no edition `{edition}` in {}", work.path.display()))?;
        let root = work.path.parent().unwrap_or(Path::new("."));

        // Offsets come from the recorded page counts rather than from reading
        // each member, so skipping to the right member costs no I/O. The read
        // below is what catches a member that no longer holds what the sidecar
        // says it does.
        let mut offset = 0u32;
        for member in &ed.members {
            if index < offset + member.pages {
                let path = root.join(&member.path);
                let within = index - offset;
                return taiyaku_read::member_page(&path, within).map_err(|e| {
                    format!(
                        "{e} — {} records {} pages for this member; it may have been replaced",
                        work.path.display(),
                        member.pages
                    )
                });
            }
            offset += member.pages;
        }
        Err(format!(
            "{edition} has {offset} pages; there is no page {index}"
        ))
    }

    fn page_count(&self, work: &Work, edition: &str) -> Result<u32, String> {
        let ed = work
            .sidecar
            .editions
            .get(edition)
            .ok_or_else(|| format!("no edition `{edition}` in {}", work.path.display()))?;
        Ok(ed.members.iter().map(|m| m.pages).sum())
    }
}
```

```rust
fn not_found(message: String) -> Response {

async fn list_works(State(state): State<Arc<ServeState>>) -> Response {

    axum::Json(ids).into_response()

    State(state): State<Arc<ServeState>>,

        return not_found(format!("no work `{work}`"));

    // loaded.

    )

async fn get_page(

    AxPath((work, edition, index)): AxPath<(String, String, u32)>,

        return not_found(format!("no work `{work}`"));

        Ok(bytes) => (

        Err(e) => not_found(e),

        .route("/api/works/{work}/{edition}/pages/{index}", get(get_page))
```

```rust
/// Where a work's progress file sits: beside its sidecar, same stem.
pub fn progress_path(work: &Work) -> PathBuf {
    let stem = work
        .path
        .file_stem()
        .map(|s| s.to_string_lossy().to_string())
        .unwrap_or_else(|| "taiyaku".to_string());
    work.path
        .parent()
        .unwrap_or_else(|| std::path::Path::new("."))
        .join(format!("{stem}.progress.json"))
}

/// What was recorded, or `None` when nothing ever was.
///
/// The distinction matters: "never opened" and "on the first page" are
/// different, and conflating them reopens a work at its cover forever.
pub fn load(work: &Work) -> Result<Option<Progress>, String> {
    let path = progress_path(work);
    match std::fs::read_to_string(&path) {
        Ok(text) => serde_json::from_str(&text)
            .map(Some)
            .map_err(|e| format!("{}: {e}", path.display())),
        Err(e) if e.kind() == std::io::ErrorKind::NotFound => Ok(None),
        Err(e) => Err(format!("{}: {e}", path.display())),
    }
}

/// Record where the reader got to.
pub fn store(work: &Work, progress: &Progress) -> Result<(), String> {
    let path = progress_path(work);
    let text = serde_json::to_string_pretty(progress)
        .map_err(|e| format!("{}: {e}", path.display()))?;
    std::fs::write(&path, text).map_err(|e| format!("{}: {e}", path.display()))
}
```

## Task 7b: Write member paths relative to the sidecar, as the format says

```rust
/// Express `target` relative to `base`, for writing into a sidecar.
///
/// The format says a member's path is relative to the sidecar, so what a
/// caller typed — which is relative to wherever they happened to be — cannot
/// be written down as-is. Both sides are canonicalised first so that `..`,
/// symlinks and differing spellings of the same directory do not produce a
/// relative path that walks somewhere else.
///
/// Falls back to the absolute path when either side cannot be canonicalised,
/// which is the honest answer: an absolute path is still correct, merely less
/// portable, and a wrong relative path would not be.
fn relative_to(target: &Path, base: &Path) -> PathBuf {
    let (Ok(target), Ok(base)) = (target.canonicalize(), base.canonicalize()) else {
        return target.to_path_buf();
    };

    let mut from = target.components().peekable();
    let mut here = base.components().peekable();
    while from.peek().is_some() && from.peek() == here.peek() {
        from.next();
        here.next();
    }

    let mut relative = PathBuf::new();
    for _ in here {
        relative.push("..");
    }
    for component in from {
        relative.push(component);
    }
    match relative.as_os_str().is_empty() {
        true => PathBuf::from("."),
        false => relative,
    }
}
```

```rust
//!
//! Gated on `TAIYAKU_CORPUS` and skipped when the archives are absent, so CI
//! stays green without them. Run locally whenever page reading changes.
//!

//! `read_edition`, the server addresses one page with `member_page`, and if
//! they ever disagree the reader shows the wrong page while every hash and
//! page count in the sidecar still matches.

use std::path::PathBuf;

use crate::{LocalLibrary, PageSource, load_works};

fn corpus_root() -> Option<PathBuf> {
    std::env::var("TAIYAKU_CORPUS").ok().map(PathBuf::from)
}

/// Every page the server serves must be byte-identical to the page the aligner
/// puts at that index. Sampling would not do: the failure mode is an offset
/// that appears at one member boundary and holds for everything after it.
#[test]
fn every_page_the_server_serves_is_the_page_the_aligner_sequenced() {
    let Some(root) = corpus_root() else {
        eprintln!("TAIYAKU_CORPUS unset — skipping");
        return;

    let sidecar = root.join("gotoubun-v01/taiyaku.json");
    if !sidecar.exists() {
        eprintln!("{} absent — skipping", sidecar.display());
        return;

    let work = &works[0];
    let dir = sidecar.parent().unwrap();

    let mut compared = 0usize;
    for (key, edition) in &work.sidecar.editions {
        let members: Vec<PathBuf> = edition.members.iter().map(|m| dir.join(&m.path)).collect();
        let sequenced = taiyaku_read::read_edition(&members).expect("aligner sequences");

        for (index, page) in sequenced.iter().enumerate() {

                .page(work, key, index as u32)
                .unwrap_or_else(|e| panic!("{key} page {index}: {e}"));
            assert_eq!(
                served,
                page.bytes,
                "{key} page {index} ({}) differs between server and aligner",
                page.name
            );
            compared += 1;
        }
    }
    eprintln!("{compared} pages compared across {} editions", work.sidecar.editions.len());
    assert!(compared > 0, "the corpus sidecar has no pages to compare");
}
```
