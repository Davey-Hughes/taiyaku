**Goal:** Close five rows on the Libraries pages, all web-only.
- O252: other directories' lines go stale after a write, and the Move and Remove dialogs' 409s do not reach the page.
- O250: a held button says nothing about why.

**Architecture:**

- Task 3: a held button's help gives the reason.

- Task 6: the dialogs' paragraph.
- Task 7: the closes in `docs/status.md`.
- Then the Finish.

There are no server changes.

**Tech Stack:** TypeScript/React (`web/`), vitest projects `node`, `jsdom` and `browser`.

**What the plan settles** (the controller's calls):

**New interfaces this plan names:**

- `LibraryPage` gains `onScan?: () => void`, called at a Scan library press.
